Built to be tiny

Everything here is plain HTML, CSS and JavaScript — no frameworks, no trackers, no network calls after the page loads. Every game is built for thumbs first, locks text selection while you play, and has a ⛶ button that takes it fullscreen. High scores are saved in your browser's local storage, so they stay on the device you play on. Finish a run and it is filed on the leaderboard under your name — handy when the phone gets passed around.
